# Eye Emotion Detector - Web Version

Clean, no-install version. Just open index.html

Features:
- Real-time webcam
- Eye detection & landmark 68 points
- Emotion: happy, sad, angry, surprised, neutral, fearful, disgusted
- Eye Aspect Ratio for blink detection
- Modern UI

How to run:
1. Double click index.html OR use Live Server in VS Code
2. Allow camera
3. Click Start Camera

Models are loaded from CDN (face-api.js). Internet needed first time.
